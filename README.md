# Atividade Prática: Crachá Geek!

## Objetivo
Uma plataforma de eventos geek precisa cadastrar participantes de campeonatos, cosplay e palestras. Sua equipe deverá criar um pequeno sistema orientado a objetos.

## Resolução
O projeto consiste em 5 Classes:
- Participante: Classe principal
- Campeonato: Derivada de participante
- Cosplay: Derivada de participante
- Palestra: Derivada de participante
- Menu

As 4 primeiras classes servem para cadastrar os participantes no sistema e poder identificá-los por categoria.
A classe Menu serve para controlar as ações do sistema, podendo cadastrar e observar os participantes cadastrados.

# Encerramento
O projeto é apenas uma demonstração de como a programação orientada a objetos pode facilitar o controle e a manipulação de dados, servindo para identificar os participantes cadastrados sem muita dificuldade.
